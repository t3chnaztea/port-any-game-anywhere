# Release audit

Status: candidate until every required gate is supported by current evidence.
Record the exact source, build artifact, reference, inventory, profile, and target.

## Inventory reconciliation

Run the ledger checker against the candidate. Reconcile every required known mode,
route, mechanic, transition, save path, failure state, and ending. State all unknowns,
approved exclusions, optional features, and unsupported conditions.

## Fidelity and device gates

Link current behavior, timing, presentation, audio, controls, persistence, and
performance results. Explain each allowed difference. Keep original behavior and
enhancements separate. Link actual target-device observations with operator and
configuration. Emulator results cannot replace these observations.

## Evidence validity

Verify input/tool/flag/environment/reference/asset identities and exact artifacts.
Account for failed, interrupted, blocked, skipped, stale, missing, and malformed
records. Confirm the tests can detect the failures they claim to exclude.
Record independent review of the public completion claims.

## Distribution

Check licenses and attribution. Exclude proprietary data, BIOS, disc images, keys,
secrets, private paths, and unrestricted session logs. Check installation from the
actual archive. Verify that all skill-relative links resolve.

## Decision

State accepted scope or the exact open gates. Name who accepted deliberate
differences and target-device evidence. Do not call an open candidate complete.
Publishing remains a separate action requiring user authorization.
