# Example evidence

`fixture.manifest.json` records exactly which source, contract, driver and tools the host comparisons use. Local run records and their logs live under `local/`.

Records report command outcomes. The ledger joins those outcomes to explicit claim IDs and evidence classes. It rejects changed inputs, missing logs and other stale identities. A successful host record does not establish actual iPhone results or a blinded recovery.

Run the commands in the [example guide](../README.md). Create the output parent first. Use a fresh record name for every new attempt. Never rewrite old fingerprints to make them current.

These records are host-bound. Other machines must rerun the checks. The public repository preserves observations rather than promising that an old pass transfers to a new environment.
