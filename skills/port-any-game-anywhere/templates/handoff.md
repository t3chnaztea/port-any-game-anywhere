# Port handoff

Status: record the current phase and any interrupted run.
Goal: one sentence naming the next completion gate.
Workspace: branch/revision plus relevant uncommitted-file identities.
Reference: edition/revision and reference-input identities.
Profile and target: names used in the ledger.
Ledger: link the authoritative ledger; do not duplicate its claims.

## Last decisive result

Record the exact command, terminal status, tested artifact identity, and evidence
path. State if this predates current edits. An interrupted run is not a pass.

## Open work

Record the active uncertainty, known failure, missing dependency/device, and any
process owned by this task. Link detailed evidence. Name resource or storage limits.

## Resume

Check workspace, storage, owned processes, inputs, tools, environment, and outputs.
Validate completed evidence before reuse. Restart interrupted work as a new run.
Record the next smallest decisive command and the result that will decide the gate.

Keep the completed handoff within 45 lines and 3.5 KB.
