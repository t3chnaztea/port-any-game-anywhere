# Worked examples

[Switchboard](recovery-puzzle/README.md) is an original complete small game with C and TypeScript implementations. Both were written from source. Its automated checks are useful preparation for a future blinded recovery trial. They do not constitute that trial.

[Fifteen](fifteen-pilot/README.md) is a pinned reproduction of an existing freely licensed browser port. Read its actual preflight status before trying a build. It is not a new implementation claim.

Each example separates expected outputs from observed results. Required physical-device checks stay open until a named operator tests the identified build. No SEGA data is included.
