# Launch-history study

**Research date: 2026-11-07.** These are dated events located in a best-effort search. “Earliest located” does not mean “first ever.” A later popular post is not necessarily a launch. Post scores and comments measure visible attention at a snapshot, not product quality or causation.

## REA

The exact repository is [morluto/rea](https://github.com/morluto/rea), the project described as reverse engineering anything. An earliest-located [Show HN item](https://news.ycombinator.com/item?id=48901763) is dated 2026-07-14. It showed 3 points and 0 comments in the researched snapshot. A [later item](https://news.ycombinator.com/item?id=50028275), dated 2026-10-10, showed 814 points and 340 comments.

**Observation:** the attention differs sharply between these two events. **Unresolved:** this study does not establish what caused that difference. It does not establish that either event was the project’s first public availability.

**Recommendation:** prepare a runnable result before broad promotion. Do not treat a quiet first post as evidence that a project cannot find users. Do not attribute a later response to the name or presentation without evidence.

## Superpowers

A [maintainer post](https://blog.fsck.com/2025/10/09/superpowers/) is dated 2025-10-09. [Simon Willison’s post](https://simonwillison.net/2025/Oct/10/superpowers/) followed on 2025-10-10. A [Hacker News discussion](https://news.ycombinator.com/item?id=45547344) is dated 2025-10-11.

**Observation:** these sources show a short sequence from author explanation to external discussion. **Unresolved:** the sequence alone cannot quantify referral traffic, adoption, or which source caused later use.

**Recommendation:** publish a technical explanation that another practitioner can reproduce and discuss. Make external review useful by including commands, expected outputs, and limits.

## uv

Astral’s [uv announcement](https://astral.sh/blog/uv), dated 2024-02-15, and Armin Ronacher’s [Rye post](https://lucumr.pocoo.org/2024/2/15/rye-grows-with-uv/) were published on the same date. A [Hacker News discussion](https://news.ycombinator.com/item?id=39387641) is also dated 2024-02-15.

**Observation:** the launch had both a project explanation and related practitioner context. **Unresolved:** this is not a controlled measurement of coordinated distribution or its effect.

**Recommendation:** explain how the skill fits an existing developer task. Pair the release with a concrete defect or recovery case. Do not imitate another project’s scale or claim its outcomes will transfer.

## Anthropic Agent Skills

The [product article](https://claude.com/resources/articles/skills) and [engineering article](https://www.anthropic.com/research/equipping-agents-for-the-real-world-with-agent-skills) are dated 2025-10-16. [Simon Willison’s explanation](https://simonwillison.net/2025/Oct/16/claude-skills/) and a [Hacker News discussion](https://news.ycombinator.com/item?id=45607117) appeared that day.

**Observation:** product framing, technical explanation, and external interpretation were available together. **Unresolved:** the existence of all three does not identify which caused users to adopt skills.

**Recommendation:** publish both the useful first task and the evidence behind the method. Keep client-specific installation outside the universal workflow. The initial release can use a versioned skill folder without a plugin framework.

## OpenRCT2

A [Neowin user post](https://www.neowin.net/forum/topic/1221451-openrct2-finally/) dated 2014-07-13 is an early located public discussion. A [Hacker News item](https://news.ycombinator.com/item?id=15456833) dated 2017-10-12 is later amplification. This study did not establish the project’s first announcement.

**Observation:** external attention occurred across years rather than one isolated launch. **Recommendation:** use verified milestones and reproductions for later updates. A project’s useful life can be longer than one announcement cycle.

## DevilutionX and its predecessor

[DevilutionX’s release history](https://github.com/diasurgical/DevilutionX/releases) records version 0.1.0 on 2019-02-27. A [predecessor Devilution README announcement pull request](https://github.com/diasurgical/devilution/pull/688) is dated 2019-03-19. These are related projects and different events. The later predecessor announcement must not be labeled DevilutionX’s first release.

**Observation:** source work, engine delivery, and an announcement can have different timelines. **Recommendation:** state whether an update concerns a specification, an implementation, a tested beta, a device-accepted build, or a public release. Do not collapse those states into “launched.”

## Plan derived from the study

The project’s [launch plan](launch-plan.md) calls for an accepted beta, one reproducible technical case study, practitioner review, and then relevant public discussion. It makes no promise of viral attention. The useful outcome is that another developer can follow the guide, identify unfinished work, and assess the evidence.
